Get help

Found a bug or have a question? Open an issue (a free GitHub account is needed). Tell us your device, the game version (shown in the lobby) and what happened.

Common questions

How do I play with friends on the same Wi-Fi?

One player taps Host. The others open the lobby and pick the host from the list, or type the host's IP address in Join by IP. Everyone must have the same game version.

The host doesn't show up in the list

On iPhone, allow Local Network access when asked (or later in Settings → Privacy & Security → Local Network). Some routers and guest networks block devices from seeing each other; use Join by IP with the address the host's lobby shows.

Can I play over the internet?

Yes. The host ticks Open port (UPnP), or forwards UDP port 24565 on the router, and shares the public address shown in the lobby. Others join it with Join by IP. A phone on mobile data usually can't host, but it can join.

Can I play alone?

Yes. Host a match and fill the seats with Bots, or play the Tutorial.
